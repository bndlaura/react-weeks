# MovieApp

React application built with Vite that lets users browse a list of movies, search and filter by title or rating, and add films to a watchlist. 

## Setup 

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/react-weeks.git
   cd react-weeks/MovieApp
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```
   Open http://localhost:5173 in your browser to see the app.


Feel free to explore the `src` directory to see how components and hooks are organized.
